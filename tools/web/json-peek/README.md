# JSON Peek (sample)

Demo tool: reads a JSON file and prints its **top-level object keys** (sorted). Uses Node built-ins only.

## Run

```bash
node tools/web/json-peek/json-peek.mjs path/to/file.json
```

Or `./start.sh` → Run tool (pass the path when the script prompts, if you extend it; today the script expects argv).
